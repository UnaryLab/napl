user-to-system
==============

.. note::

   This page is a placeholder for a planned path. Nothing described here exists
   in code yet.

The user-to-system path is the planned lowering of a whole user program to a
full system's RTL, beyond the single library classes the current
:doc:`napl_to_rtl` path handles. Where napl-to-RTL resolves each napl class to
its own verified Verilog module, the whole-system path would take a complete
program built on napl's public API and emit the RTL for the system that runs
it.

Its scope is not yet fixed and no behavior is committed. This page will be
filled in as the path is designed and built.
